# 🎬 Medo TV - موقع مشاهدة الأفلام والمسلسلات

موقع متكامل وحديث لمشاهدة الأفلام والمسلسلات العربية والأجنبية بجودة عالية.

## ✨ الميزات الرئيسية

- 🔍 **البحث والتصفية المتقدمة** - ابحث عن أي فيلم أو مسلسل بسهولة
- ❤️ **قائمة المفضلة** - احفظ أفضل اختياراتك واعودت إليها لاحقاً
- ⏸️ **قيد المشاهدة** - تابع آخر ما شاهدته من محتوى
- 📊 **تصنيفات متعددة** - رمضان، خليجي، عربي، تركي، أجنبي
- 📱 **متجاوب تماماً** - يعمل بشكل مثالي على جميع الأجهزة والشاشات
- 🎥 **مشغل فيديو احترافي** - شاهد الحلقات بسهولة وتحكم كامل
- 💾 **تخزين محلي آمن** - احفظ بيانات المفضلة محليًا على جهازك
- 🚀 **سرعة عالية** - واجهة سريعة وسلسة

## 🚀 ال��دء السريع

### الطريقة 1: فتح مباشر
1. انسخ الملفات الثلاث (`index.html` و `styles.css` و `app.js`)
2. افتح `index.html` في المتصفح مباشرة

### الطريقة 2: استضافة محلية
```bash
# استخدم Python
python -m http.server 8000

# أو استخدم Node.js
npx http-server
```

### الطريقة 3: استضافة على الويب
- ارفع الملفات على أي خادم ويب (Netlify, Vercel, GitHub Pages، إلخ)

## 🎯 كيفية الاستخدام

### البحث عن محتوى
1. استخدم شريط البحث العلوي
2. اكتب اسم الفيلم أو المسلسل
3. سيظهر لك النتائج مباشرة

### اختيار من التصنيفات
1. اختر التصنيف المطلوب (الكل، رمضان، خليجي، إلخ)
2. ستُصفى القائمة تلقائياً

### مشاهدة المحتوى
1. انقر على الفيلم أو المسلسل
2. انقر على زر "شاهد الآن"
3. اختر الحلقة من القائمة الجانبية
4. استمتع بالمشاهدة!

### حفظ المفضلة
1. انقر على أيقونة القلب ❤️
2. سيتم حفظها تلقائياً
3. يمكنك الوصول إليها من قائمة المفضلة

## 🛠️ التكنولوجيات المستخدمة

| التقنية | الوصف |
|---------|-------|
| **HTML5** | الهيكل الأساسي للموقع |
| **CSS3** | التنسيق المتقدم والديزاين الحديث |
| **Vanilla JavaScript** | التفاعلات والوظائف الديناميكية |
| **Alooy API** | مصدر البيانات الموثوق |
| **LocalStorage** | تخزين البيانات محليًا |

## 📊 مصدر البيانات

يستخدم الموقع **Alooy API** والتي توفر:
- **1332+** فيلم ومسلسل مختلف
- **تصنيفات شاملة** - محتوى متنوع
- **جودة عالية** - فيديوهات بصيغة MP4
- **تحديثات مستمرة** - محتوى جديد بشكل دائم

### معلومات الـ API
```
الرابط الأساسي: https://api.dfkz.site/alooy/
البحث: https://api.dfkz.site/alooy/?q=
التفاصيل: https://api.dfkz.site/alooy/series.php?id=
```
